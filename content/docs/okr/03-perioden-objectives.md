# Perioden und Zielsetzungen

In diesem Kapitel lernst du, wie du Perioden als Zeitrahmen für deine Ziele anlegst und konkrete Zielsetzungen (Objectives) formulierst.

## Perioden verstehen

### Was ist eine Periode?

Eine **Periode** ist ein definierter Zeitabschnitt, in dem Ziele verfolgt werden. Typischerweise sind dies Quartale, aber du kannst beliebige Zeiträume definieren.

In einem Zielsystem vom Typ **Managementbewertung** bildet eine Periode stattdessen eine konkrete Bewertungsrunde ab. Sie enthält Bewertungsthemen, Teilnehmende, Gesamtbeurteilung und Abschlussnachweis. Siehe [Managementbewertung durchführen](../managementbewertung/).

| Feld | Beschreibung | Beispiel |
|------|--------------|----------|
| **Titel** | Name der Periode | "Q1 2025" |
| **Beschreibung** | Optionale Details | "Fokus auf Kundenbindung" |
| **Beginn** | Startdatum | 01.01.2025 |
| **Ende** | Enddatum | 31.03.2025 |
| **Verantwortung** | Zuständige Personen | Team-Leads |
| **Status** | Aktueller Stand | in Planung, in Bearbeitung, erledigt |

### Status einer Periode

| Status | Bedeutung | Wann verwenden |
|--------|-----------|----------------|
| **in Planung** | Periode wird vorbereitet | Vor dem Startdatum |
| **in Bearbeitung** | Aktiv | Während der Laufzeit |
| **erledigt** | Abgeschlossen | Nach dem Enddatum |

## Periode erstellen

### Schritt-für-Schritt Anleitung

1. Öffne das gewünschte Zielsystem
2. Klicke auf den grünen Button **"Periode"** (+ Symbol)
3. Fülle die Felder aus:
   - **Titel**: z.B. "Q1 2025"
   - **Startdatum**: Beginn der Periode
   - **Enddatum**: Ende der Periode
4. Klicke auf **"Speichern"**

### Objectives aus vorheriger Periode übernehmen

Beim Erstellen einer neuen Periode kannst du bestehende Objectives übernehmen:

1. Wenn eine vorherige Periode existiert, werden deren Objectives angezeigt
2. Aktiviere die Checkboxen für die Objectives, die du übernehmen möchtest
3. Die ausgewählten Objectives werden in die neue Periode kopiert

> **💡 Tipp:** Dies spart Zeit bei wiederkehrenden Zielen!

## Periode bearbeiten

1. Öffne die Periode (klicke auf den Titel in der Perioden-Tabelle)
2. Klicke auf das **Stift-Symbol** (Bearbeiten)
3. Nimm deine Änderungen vor
4. Klicke auf **"Speichern"**

### Bearbeitbare Felder

- **Zielsystem**: Kann geändert werden (Periode verschieben)
- **Titel**: Name der Periode
- **Beschreibung**: Details und Kontext
- **Beginn/Ende**: Zeitraum anpassen
- **Verantwortung**: Zuständige Personen
- **Bild**: Visuelles Element
- **Status**: Aktueller Stand

## Periode löschen

> **⚠️ Wichtig:** Das Löschen einer Periode entfernt auch alle zugehörigen Objectives und Key Results!

Eine abgeschlossene Managementbewertungsperiode kann weder bearbeitet noch gelöscht werden.

1. Öffne die Periode
2. Klicke auf das **Papierkorb-Symbol**
3. Bestätige die Löschung

Du wirst zum übergeordneten Zielsystem weitergeleitet.

## Navigation zwischen Perioden

In der Detailansicht einer Periode kannst du:

- **Vorherige Periode**: Mit dem linken Pfeil zur vorherigen Periode navigieren
- **Nächste Periode**: Mit dem rechten Pfeil zur nächsten Periode navigieren

Die Navigation basiert auf dem Startdatum der Perioden.

## Zielsetzungen (Objectives)

### Was ist ein Objective?

Ein **Objective** (Zielsetzung) beschreibt ein qualitatives Ziel, das innerhalb einer Periode erreicht werden soll.

| Feld | Beschreibung | Beispiel |
|------|--------------|----------|
| **Titel** | Kurze, inspirierende Beschreibung | "Kundenzufriedenheit steigern" |
| **Beschreibung** | Details und Kontext | "Fokus auf Support-Qualität" |
| **Periode** | Zugehörige Periode | "Q1 2025" |
| **Verantwortung** | Zuständige Personen | Projektleiter |
| **Status** | Aktueller Stand | Entwurf, freigegeben, etc. |

### Status-Workflow

Ein Objective durchläuft folgende Status:

<pre>
┌─────────┐   ┌────────────┐   ┌──────────────┐   ┌─────────────┐
│ Entwurf │ → │ Freigegeben│ → │ In Bearbeitung│ → │ Abgeschlossen│
└─────────┘   └────────────┘   └──────────────┘   └─────────────┘
                                                          │
                                                    ┌─────┴─────┐
                                                    │ Abgebrochen│
                                                    └───────────┘
</pre>

| Status | Bedeutung |
|--------|-----------|
| **Entwurf** | Noch in Arbeit, nicht sichtbar für alle |
| **Freigegeben** | Zur Umsetzung freigegeben |
| **In Bearbeitung** | Aktiv in Arbeit |
| **Abgeschlossen** | Erfolgreich beendet |
| **Abgebrochen** | Vorzeitig beendet |

## Objective erstellen

### Schritt-für-Schritt Anleitung

1. Öffne die gewünschte Periode
2. Klicke auf den grünen Button **"Zielsetzung hinzufügen"**
3. Fülle die Felder aus:
   - **Titel**: Aussagekräftiger Name
   - **Beschreibung**: Optionale Details
4. Klicke auf **"Speichern"**

### Formulierungstipps für Objectives

> **💡 Tipp:** Ein gutes Objective ist:
> - **Qualitativ**: Beschreibt einen Zustand, keine Zahl
> - **Inspirierend**: Motiviert das Team
> - **Ambitioniert**: Herausfordernd, aber erreichbar
> - **Klar**: Jeder versteht, was gemeint ist

**Beispiele für gute Objectives:**

| ✅ Gut | ❌ Schlecht |
|--------|------------|
| "Unsere Kunden lieben unseren Support" | "10 Support-Tickets pro Tag bearbeiten" |
| "Marktführer in der Schweiz werden" | "30% Marktanteil erreichen" |
| "Ein Team, auf das wir stolz sind" | "5 neue Mitarbeiter einstellen" |

> Die messbaren Zahlen gehören in die Key Results, nicht ins Objective!

## Objective bearbeiten

1. Öffne das Objective
2. Klicke auf das **Stift-Symbol**
3. Nimm deine Änderungen vor
4. Klicke auf **"Speichern"**

### Zusätzliche Felder beim Bearbeiten

- **Periode**: Objective einer anderen Periode zuordnen
- **Beteiligte Prozesse**: Verknüpfung mit Prozessen aus dem Prozess-Modul
- **Beteiligte Projekte**: Verknüpfung mit Projekten
- **KPIs**: Verknüpfung mit Kennzahlen aus dem KPI-Modul
- **Bild**: Visuelles Element

## Objectives sortieren (Drag & Drop)

Im Jahresplaner kannst du Objectives per Drag & Drop neu ordnen:

1. Öffne den Jahresplaner des Zielsystems
2. Ziehe ein Objective an die gewünschte Position
3. Du kannst Objectives auch zwischen Perioden verschieben

## Verknüpfungen nutzen

### Mit Prozessen verknüpfen

Objectives können mit Prozessen aus dem Prozess-Modul verknüpft werden:

1. Bearbeite das Objective
2. Im Feld **"Beteiligte Prozesse"** wähle die relevanten Prozesse
3. Speichere

Die verknüpften Prozesse werden in der Detailansicht angezeigt.

### Mit Projekten verknüpfen

Verbinde Objectives mit Projekten:

1. Bearbeite das Objective
2. Im Feld **"Beteiligte Projekte"** wähle die Projekte
3. Speichere

### Mit KPIs verknüpfen

Verknüpfe relevante Kennzahlen:

1. Bearbeite das Objective
2. Im Feld **"KPIs"** wähle die Kennzahlen
3. Speichere

> **💡 Tipp:** Verknüpfungen schaffen Kontext und zeigen Zusammenhänge auf!

## Fortschritt verfolgen

### Fortschrittsberechnung

Der Fortschritt eines Objectives berechnet sich automatisch:

```
Objective-Fortschritt = Durchschnitt aller Key Result-Fortschritte
```

Beispiel: Wenn ein Objective 3 Key Results hat mit 50%, 75% und 25% Fortschritt, beträgt der Gesamtfortschritt 50%.

### Fortschrittsanzeige

In der Perioden-Übersicht siehst du:

- **Fortschrittsbalken** für jedes Objective
- **Geschätzte Kosten** (Summe aller Key Results)
- **Geschätzter Aufwand** in Personentagen

## Perioden-Übersicht

Die Detailansicht einer Periode zeigt:

### Objektive-Tabelle

| Spalte | Beschreibung |
|--------|--------------|
| Zielsetzung | Name mit Link |
| Fortschritt | Prozentbalken |
| Geschätzte Kosten | Budget in CHF |
| Geschätzter Aufwand | Personentage |
| Verantwortung | Team-Mitglieder |
| Status | Aktueller Stand |

### Aufwand pro Person

Die Ansicht zeigt auch den **geschätzten Aufwand pro Person**, basierend auf den zugewiesenen Key Results.

## Meine Zielsetzungen

Zeige nur Objectives, für die du verantwortlich bist:

1. Navigiere zu **OKR** → **Alle Zielsetzungen**
2. Wähle **"Meine Zielsetzungen"** im Untermenü

Diese Ansicht zeigt nur aktive Objectives (Entwurf, freigegeben, in Bearbeitung).

## Best Practices

### ✅ Für Perioden

- **Konsistente Länge**: Verwende einheitliche Zeiträume (z.B. immer Quartale)
- **Vorausschauend planen**: Lege die nächste Periode an, bevor die aktuelle endet
- **Status aktuell halten**: Ändere den Status, wenn die Periode startet/endet
- **Objectives übernehmen**: Nutze die Kopierfunktion für wiederkehrende Ziele

### ✅ Für Objectives

- **3-5 pro Periode**: Weniger ist mehr - fokussiere dich
- **Qualitativ formulieren**: Zahlen gehören in die Key Results
- **Verantwortliche zuweisen**: Jedes Objective braucht einen Owner
- **Verknüpfungen nutzen**: Schaffe Kontext durch Links zu Prozessen/Projekten

### ❌ Zu vermeiden

- Zu viele Objectives pro Periode
- Objectives ohne klare Verantwortung
- Zu lange Perioden (>6 Monate)
- Status nicht aktualisieren

## Häufige Fragen

### Wie viele Objectives pro Periode?

Empfohlen sind 3-5 Objectives. Bei mehr als 5 wird der Fokus verwässert.

### Kann ich ein Objective verschieben?

Ja, beim Bearbeiten kannst du die Periode ändern oder im Jahresplaner per Drag & Drop verschieben.

### Was passiert mit Key Results, wenn ich ein Objective lösche?

Alle zugehörigen Key Results werden ebenfalls gelöscht.

### Wann sollte ich den Status ändern?

- **Freigegeben**: Wenn das Objective zur Umsetzung bereit ist
- **In Bearbeitung**: Wenn aktiv daran gearbeitet wird
- **Abgeschlossen**: Wenn alle Key Results erreicht wurden
- **Abgebrochen**: Wenn das Ziel nicht mehr relevant ist
