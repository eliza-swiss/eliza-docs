# Organisationseinheiten und Organigramm

In diesem Kapitel lernst du, wie du Organisationseinheiten erstellst, Hierarchien definierst und das Organigramm nutzt.

## Was sind Organisationseinheiten?

Organisationseinheiten (Orgunits) bilden die Struktur deines Unternehmens ab. Sie können verschiedene Formen annehmen:

| Typ | Beispiele |
|-----|-----------|
| **Abteilungen** | Marketing, IT, Finanzen, HR |
| **Teams** | Entwicklungsteam A, Support-Team |
| **Standorte** | Zürich, Basel, Bern |
| **Bereiche** | Produktion, Vertrieb, Service |
| **Projekte** | Projekt Alpha, Transformation 2025 |

## Organisationseinheiten verwalten

### Zur Liste navigieren

1. Klicke auf **Organisation** in der Hauptnavigation
2. Wähle **Organisationen** aus dem Menü
3. Die Liste aller Organisationseinheiten wird angezeigt

### Spalten in der Liste

| Spalte | Beschreibung |
|--------|--------------|
| **Nummer** | Optionale Nummerierung |
| **Titel** | Name der Organisationseinheit |
| **Typ** | Art der Organisation |
| **Übergeordnet** | Parent-Organisation |
| **Leitung** | Verantwortliche Person |
| **Status** | Entwurf, Aktiv, Archiviert |

### Eine Organisationseinheit erstellen

**Schritt 1: Formular öffnen**

1. Navigiere zu **Organisation** → **Organisationen**
2. Klicke auf **"Hinzufügen"** (grüner Button)
3. Das Erfassungsformular öffnet sich

**Schritt 2: Grunddaten eingeben**

| Feld | Beschreibung | Pflicht |
|------|--------------|---------|
| **Titel** | Name der Organisationseinheit | Ja |
| **Nummer** | Optionale Kennung/Nummer | Nein |
| **Organisationsart** | Typ (Abteilung, Team, etc.) | Nein |
| **Übergeordnete Organisation** | Parent in der Hierarchie | Nein |
| **Leitung** | Verantwortliche Person | Nein |
| **Status** | Aktiv, Entwurf, Archiviert | Ja |

**Schritt 3: Details ergänzen**

| Feld | Beschreibung |
|------|--------------|
| **Beschreibung** | Ausführliche Beschreibung |
| **Adresse** | Standortadresse |
| **PLZ / Ort** | Postleitzahl und Stadt |
| **Telefon** | Kontakttelefon |
| **E-Mail** | Kontakt-E-Mail |
| **Website** | Webseite der Einheit |
| **Reihenfolge** | Sortierung in Listen |
| **Im Organigramm anzeigen** | Sichtbarkeit im Organigramm |
| **Planstellen in %** | Geplante Stellenprozente |

**Schritt 4: Spezielle Einstellungen**

| Feld | Beschreibung |
|------|--------------|
| **Stabsstelle** | Im Organigramm als Stabsstelle darstellen |
| **Partner** | Als Partner darstellen |
| **Farbe** | Individuelle Farbe im Organigramm |
| **Vertikal ab Stufe** | Ab welcher Ebene vertikal darstellen |

**Schritt 5: Speichern**

1. Überprüfe die Eingaben
2. Klicke auf **"Speichern"**
3. Die Organisationseinheit wird angelegt

### Organisationseinheit bearbeiten

1. Klicke in der Liste auf den Namen der Organisationseinheit
2. Die Detail-Ansicht öffnet sich
3. Klicke auf **"Bearbeiten"**
4. Ändere die gewünschten Felder
5. Speichere die Änderungen

### Untergeordnete Einheit erstellen

Du kannst direkt aus einer Organisationseinheit heraus eine untergeordnete Einheit erstellen:

1. Öffne die Detail-Ansicht der übergeordneten Einheit
2. Klicke auf **"Unterorganisation hinzufügen"**
3. Die übergeordnete Organisation ist bereits vorausgewählt
4. Fülle die restlichen Daten aus
5. Speichere

## Organisationsarten

Organisationsarten helfen, verschiedene Typen zu unterscheiden:

### Organisationsarten verwalten

1. Navigiere zu **Organisation** → **Dashboard**
2. Klicke auf **Organisationsarten**
3. Oder: **Einstellungen** → **Organisationsarten**

### Eine Organisationsart erstellen

1. Klicke auf **"Hinzufügen"**
2. Gib Titel und Beschreibung ein
3. Speichere

**Typische Organisationsarten:**

| Art | Beschreibung |
|-----|--------------|
| **Abteilung** | Organisatorische Haupteinheit |
| **Team** | Arbeitsgruppe innerhalb einer Abteilung |
| **Bereich** | Übergeordneter Geschäftsbereich |
| **Stabsstelle** | Unterstützende Funktion |
| **Standort** | Geografischer Standort |
| **Projekt** | Temporäre Projektorganisation |

## Das Organigramm

### Organigramm aufrufen

1. Navigiere zu **Organisation** → **Organigramm**
2. Das interaktive Organigramm wird angezeigt

> **💡 Tipp:** Je nach Konfiguration kann es verschiedene Organigramm-Ansichten geben.

### Organigramm-Funktionen

**Navigation:**
- **Zoomen**: Mausrad oder +/- Buttons
- **Verschieben**: Klicken und Ziehen
- **Details**: Klick auf eine Box öffnet Details

**Darstellung:**
- Organisationseinheiten werden als Boxen dargestellt
- Linien zeigen die Hierarchie
- Farben können pro Einheit definiert werden
- Stabsstellen werden seitlich angezeigt

### Wer wird im Organigramm angezeigt?

Im Organigramm erscheinen:

- **Organisationseinheiten** mit aktivem Status
- **Leitungen** der Einheiten
- **Mitglieder** (abhängig von der Konfiguration)

**Ausblenden:**
- Setze "Im Organigramm anzeigen" auf "Nein" bei der Organisationseinheit
- Bei Mitgliedschaften: "Im Organigramm anzeigen" deaktivieren

### Organigramm-Einstellungen

Administratoren können die Organigramm-Darstellung konfigurieren:

1. Navigiere zu **Organisation** → **Organigramm**
2. Klicke auf **Einstellungen** (Zahnrad-Icon)

**Verfügbare Einstellungen:**

| Einstellung | Beschreibung |
|-------------|--------------|
| **Startebene** | Von welcher Ebene aus anzeigen |
| **Max. Tiefe** | Wie viele Ebenen anzeigen |
| **Darstellung** | Horizontal oder Vertikal |
| **Mitglieder anzeigen** | Ob Mitglieder sichtbar sind |

## Management-Ansicht

> **⚠️ Hinweis:** Diese Funktion muss aktiviert sein (`ORGANISATION_USE_MANAGEMENT`).

Die Management-Ansicht zeigt die Führungsstruktur:

### Management-Ansicht aufrufen

1. Navigiere zu **Organisation** → **Management**
2. Die Führungshierarchie wird angezeigt

### Was zeigt die Management-Ansicht?

- **Vorgesetzte**: Wer berichtet an wen
- **Teams**: Direkte Mitarbeitende pro Führungskraft
- **Hierarchie-Ebenen**: Von der Geschäftsleitung abwärts

> **💡 Tipp:** Die Management-Ansicht basiert auf dem Feld "Vorgesetzter" bei Mitarbeitenden, nicht auf Organisationseinheiten.

## Mitgliedschaften verwalten

Mitgliedschaften verbinden Mitarbeitende mit Organisationseinheiten.

### Eine Mitgliedschaft erstellen

**Variante 1: Vom Mitarbeitenden aus**

1. Öffne die Detail-Ansicht des Mitarbeitenden
2. Navigiere zum Tab **"Mitgliedschaften"**
3. Klicke auf **"Hinzufügen"**
4. Wähle die Organisationseinheit
5. Optional: Wähle eine Funktion
6. Speichere

**Variante 2: Von der Organisationseinheit aus**

1. Öffne die Detail-Ansicht der Organisationseinheit
2. Scrolle zu **"Mitglieder"**
3. Klicke auf **"Mitglied hinzufügen"**
4. Wähle den Mitarbeitenden
5. Optional: Wähle eine Funktion
6. Speichere

### Mitgliedschafts-Felder

| Feld | Beschreibung |
|------|--------------|
| **Mitarbeiter** | Der Mitarbeitende |
| **Organisationseinheit** | Die Ziel-Organisation |
| **Funktion** | Optionale Funktion in dieser Einheit |
| **Von** | Startdatum der Mitgliedschaft |
| **Bis** | Enddatum (leer = unbefristet) |
| **Anstellungsgrad** | Stellenprozente in dieser Einheit |
| **Beschreibung** | Zusätzliche Informationen |
| **Reihenfolge** | Sortierung in Listen |
| **Im Organigramm anzeigen** | Sichtbarkeit im Organigramm |
| **Qualifikation** | Optionale Qualifikationsstufe |

### Mehrfache Mitgliedschaften

Ein Mitarbeitender kann mehreren Organisationseinheiten angehören:

- **Hauptabteilung** (z.B. 80%)
- **Projektteam** (z.B. 20%)
- **Arbeitsgruppe** (ohne Stellenprozente)

> **💡 Tipp:** Die Summe der Stellenprozente sollte dem Gesamtanstellungsgrad entsprechen.

### Mitgliedschaft beenden

1. Öffne die Mitgliedschaft (vom Mitarbeitenden oder der Organisation aus)
2. Klicke auf **"Bearbeiten"**
3. Setze das **"Bis"**-Datum
4. Speichere

> **⚠️ Wichtig:** Beendete Mitgliedschaften bleiben historisch erhalten, werden aber nicht mehr in aktuellen Listen angezeigt.

## Aufbauorganisation

Die Aufbauorganisation zeigt die vollständige Hierarchie:

### Aufbauorganisation aufrufen

1. Navigiere zu **Organisation** → **Dashboard**
2. Klicke auf **"Organisationseinheiten"**
3. Oder direkt: **Organisation** → **Aufbauorganisation**

### Darstellung

Die Aufbauorganisation zeigt:

- **Baumstruktur**: Hierarchisch verschachtelte Ansicht
- **Alle Ebenen**: Von der Wurzel bis zu den Blättern
- **Mitglieder**: Anzahl und Liste der Mitglieder
- **Status**: Aktiv, Entwurf, Archiviert

## Administratoren und HR-Admins

Jede Organisationseinheit kann eigene Administratoren haben:

### Admins zuweisen

1. Öffne die Detail-Ansicht der Organisationseinheit
2. Klicke auf **"Bearbeiten"**
3. Füge unter **"Admins"** Benutzer hinzu
4. Füge unter **"HR Admins"** Benutzer hinzu
5. Speichere

### Unterschied Admin vs. HR Admin

| Rolle | Berechtigungen |
|-------|----------------|
| **Admin** | Kann Mitarbeitende dieser Einheit verwalten |
| **HR Admin** | Kann zusätzlich private Daten und HR-Dokumente verwalten |

> **💡 Tipp:** Diese lokalen Administratoren können Mitarbeitende verwalten, auch ohne globale Admin-Berechtigung.

## Kostenstellen

> **⚠️ Hinweis:** Dieses Modul muss aktiviert sein (`ORGANISATION_USE_COSTCENTERS`).

### Kostenstellen verwalten

1. Navigiere zu **Organisation** → **Kostenstellen**
2. Die Liste aller Kostenstellen wird angezeigt

### Eine Kostenstelle erstellen

1. Klicke auf **"Hinzufügen"**
2. Fülle aus:
   - **Titel**: Name der Kostenstelle
   - **Beschreibung**: Details
   - **Leitung**: Verantwortliche Person
3. Speichere

### Mitarbeitende zu Kostenstellen zuordnen

1. Öffne das Profil des Mitarbeitenden
2. Klicke auf **"Bearbeiten"**
3. Wähle im Feld **"Kostenstelle"** die gewünschte Kostenstelle
4. Speichere

## Best Practices

### ✅ Empfehlungen

1. **Klare Hierarchie**: Definiere eine eindeutige Baumstruktur
2. **Konsistente Benennung**: Verwende einheitliche Namen
3. **Aktuelle Daten**: Halte Mitgliedschaften aktuell
4. **Dokumentation**: Nutze Beschreibungsfelder
5. **Leitungen definieren**: Jede Einheit sollte eine Leitung haben

### ❌ Häufige Fehler

1. **Zu tiefe Hierarchie**: Maximal 4-5 Ebenen empfohlen
2. **Fehlende Parent-Zuordnung**: Verwaiste Einheiten vermeiden
3. **Veraltete Mitgliedschaften**: Regelmässig prüfen
4. **Inkonsistente Struktur**: Einheitliche Logik beibehalten
